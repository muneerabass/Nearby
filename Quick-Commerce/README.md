# Emblem — quick-commerce app

React Native + TypeScript quick-commerce client for Emblem. The app has customer,
admin and delivery-partner role flows and communicates with the Go/PostgreSQL API
through the service layer under `src/services`.

## Running it

```bash
npm install
npx expo start
```

For a physical phone, set `EXPO_PUBLIC_API_URL` to a reachable LAN or deployed
backend URL. `localhost` only works for the iOS simulator and `10.0.2.2` only
works for the Android emulator. Distribution builds fail if the API URL is a
loopback, emulator or tunnel address.

Then press `i` for the iOS simulator or `a` for an Android emulator.

The `ios/` directory is generated by `npx expo prebuild`. To rebuild natively:

```bash
npx expo run:ios
```

If CocoaPods fails with a `unicode_normalize` error, run it with an explicit locale:
`LANG=en_US.UTF-8 pod install` from `ios/`.

## Architecture

```
src/
  theme/        design tokens — colors, spacing, typography, shadows, responsive layout
  types/        domain models (Product, Category, CartItem, User, Address)
  data/         storefront category presentation and image metadata
  services/     API client, auth/catalog/cart/order/admin/delivery services
  context/      auth, addresses, cart, catalog, admin and delivery providers
  hooks/        debouncing, polling, recent searches and location helpers
  components/   reusable UI, all theme-driven
  navigation/   Root → (Splash | Auth | Main) → Tabs + pushed stack screens
  screens/      one folder per feature area
```

### Client/backend contracts

Every network boundary is asynchronous and returns the backend DTO-shaped view model:

| Seam | File | Replaces |
| --- | --- | --- |
| Auth | `src/services/authService.ts` | `POST /auth/otp/request`, `/verify`, `/signup` |
| Catalog | `src/services/catalogService.ts` | `GET /api/v1/catalog/products` |
| Categories | `src/services/adminService.ts` | `GET /api/v1/admin/categories` |
| Cart | `src/context/CartContext.tsx` and `cartService.ts` | `/api/v1/cart*` |
| Orders | `src/services/orderService.ts` | `/api/v1/orders*` |
| Delivery | `src/services/deliveryService.ts` | `/api/v1/delivery/*` |

The backend is a single Go service with Fiber handlers, service-layer business
rules, GORM repositories and PostgreSQL migrations. It is intentionally a
monolith suitable for the initial 500–1,000-user target.

## Notes

- **State**: Context plus local state; no Redux is required for the current scope.
- **Cart** is server-backed and refreshed against the selected address.
- **Images** are remote photographs; each URL was fetched and visually checked against the
  product it is filed under. `ProductImage` falls back to an illustrated emoji tile on load
  failure, so the grid never shows an empty box offline.
- **Animations** use Reanimated on the UI thread: press-scale, add-to-cart width spring,
  cart badge pop, tab indicator, staggered list entrances.
- **Checkout** is a real COD flow. Online payments, coupons, notifications and live GPS tracking are not implemented yet.

## Backend development

```bash
cd ../backend-go
cp .env.example .env
make db-up
make run
```

The backend runs migrations at startup. Never point integration tests at a
production database. Use `TEST_DB_URL` for the PostgreSQL integration suite.

Database pool settings are environment-based: `DB_MAX_OPEN_CONNS` and
`DB_MAX_IDLE_CONNS` apply per backend instance, while lifetime settings control
connection recycling. With Cloud Run `max-instances=3` and the defaults of 10
open connections per instance, the service can use up to roughly 30 application
connections; leave headroom below the Cloud SQL limit for migrations,
administrative tools and other clients.

## Checks

```bash
npm test -- --runInBand
npx tsc --noEmit
npx expo config --type public
cd ../backend-go && go test ./... && go build ./...
make secrets-scan # requires gitleaks
```

The secret scan uses the repository `.gitleaks.toml` and redacts findings. Local
`.env` files are ignored; if a real credential has ever been exposed, rotate it
rather than relying on Git history cleanup alone.
